The menu is what both the browser and the bridge speak. Opus unless a specific interop problem says otherwise — G.711 spends 64 kbps sounding worse than Opus at 24.

{% icon "download-tray" 16 %} Transport (ICE)

Relay-only needs a TURN server below, or no call connects at all. It is the lever for networks where direct UDP between machines is forbidden.

On a server with more than one interface: the one address every subnet reaches (the one staff load the Hub from). Empty advertises all interfaces, which is how cross-subnet audio goes one-way.

Needed for mesh calls that cross the VPN or leave the building; bridge calls only need the server itself to be reachable. Empty falls back to settings.py. WebRTC media is UDP; a TURN entry with ?transport=tcp or turns:…:443 is the way through networks that allow only TCP out.
