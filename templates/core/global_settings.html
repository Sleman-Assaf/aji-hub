Somebody’s calendar is matched to their Hub account by email address, so a person with no email address on their account keeps seeing the Hub calendar. Azure setup: on the same App Registration used for email, add the application permission Calendars.Read under Microsoft Graph and grant admin consent. No new secret and no redirect URL are needed.

Worth knowing before you switch it on: Calendars.Read as an application permission lets the Hub read every mailbox in the tenant, not only the calendar of whoever is looking. If IT would rather scope that down, ask them for an application access policy limiting this app registration to a specific mail-enabled security group.
